How to Deploy a Web Application Using Docker and NGINX on Your Own Server

#webdev  #devops

Deploying a web application doesn't need to be a complicated process. With Docker, NGINX, and your own server, you can get your app live in no time.

In this blog, I'll walk through how to serve an app with a domain, route traffic through NGINX, and run everything inside a Docker container. This guide is tailored for a Linux-based server.

Step 1 : Setup docker

First, set up Docker. Any application or codebase can be used as an example. Create a Dockerfile in the project directory to define how the app should be containerized.

Dockerfile:

FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
CMD [ "npm", "start" ]

Step 2 : Build and Run the Docker Container (on your server)

Once the Dockerfile is ready, the next step is to build the Docker image and run it to make sure everything is working as expected.

Conclusion

Deploying a web application using Docker and NGINX on your own server may sound intimidating at first, but once broken down, it is quite manageable.

By containerizing the app, setting up NGINX as a reverse proxy, and linking everything together on the VPS, full control over the deployment process is gained.
